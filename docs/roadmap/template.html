Généré depuis la revue du commit . Les rapports détaillés et la version Markdown pour les agents sont dans docs/roadmap/ du dépôt.
Page en lecture seule : les statuts viennent de docs/roadmap/status.json. Pour en changer un : node docs/roadmap/status.mjs <id> <statut> [note], qui régénère cette page et ROADMAP.md. L’identifiant est celui d’une tâche (SEC-02) ou d’un point de l’audit préfixé par audit- (audit-B1, audit-A6-M2).
Lien direct vers une tâche : ajoutez son identifiant après # dans l’URL, par exemple #SEC-02. Pour l’audit : #B1, #D5, #T3, #A6-M2 pour un constat, ou #audit-constats pour une vue.
